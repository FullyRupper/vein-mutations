# Vein: Mutations

A hardcore mutation mod for **Minecraft Java 1.21.1 (Fabric)**.

Vanilla survival infects you. Four veins — **Pupil**, **Bone**, **Shadow**, and **Flesh** — grow out of darkness, fists, stealth, and hunger. Vein XP is a second currency. You choose which vein to feed. Power comes first. The price comes after.

**This repository is the public issue tracker.** Use it for bugs, crashes, and balance reports. There is no Discord.

- CurseForge: https://www.curseforge.com/minecraft/mc-mods/vein-mutations
- Author: Fully_Rupper

Requires Fabric Loader, Fabric API, and Java 21. Client and dedicated server. Sodium and Iris are fine.

## Before you open an issue

Search existing issues first. If you found the same thing, comment there instead of making a duplicate.

One issue = one problem. Do not dump five bugs into a single ticket.

## Bug report

Use this template:

**What you were doing:**

**Can you reproduce it:** yes / no / sometimes  

Attach `latest.log` from `.minecraft/logs/`, or the crash report if the game closed. A screenshot of the vein screen (`K`) helps if the bug is about ranks, Pour, or strain.

## What belongs here

- Crashes and freezes
- A vein giving the wrong effect, cost, or keybind
- Something that works in singleplayer but breaks on a server
- Translation mistakes in English or Russian
- A balance problem you can describe with numbers, not just “too strong”

## What does not belong here

- “The mod does not work” with no version and no log
- Forge / NeoForge — this build is Fabric 1.21.1 only
- Texture pack conflicts, unless you can show Vein itself is the cause
- Feature ideas with no example of how they should work in-game

If the report has no version and no log, it will be closed.
